# OPUS Landing Page

This package is the `opus.mk` marketing site for the current beauty appointment product in Macedonia. Its copy must describe only behavior that is genuinely available in the dashboard and automatic studio websites. `opus-mk/` is a separate dormant marketplace package.

Read the repository-wide [product scope](../docs/PRODUCT_SCOPE.md) before product work. Do not advertise hospitality, unsupported provider delivery, trial pricing, autonomous AI, international expansion, or native clients as active. The Expo/React Native and SwiftUI apps come last and are outside the current web phase.

## Development

```bash
npm install
npm run dev
```
