# OPUS marketing video

Custom Remotion composition for a 20-second OPUS social ad. The dark visual
system follows the supplied OPUS feed-post references: Commissioner for
functional copy, Lora italic for editorial emphasis, the near-black/coral
palette, and the supplied abstract light texture. Product UI is rebuilt as
React components instead of being enlarged from screenshots, so it stays sharp
in both the 1080×1920 delivery and the 2160×3840 master.

## Storyboard

1. Appointment messages become difficult to manage.
2. OPUS brings the schedule into one clear calendar.
3. A customer books through the studio's OPUS link.
4. The confirmed appointment appears in the studio calendar.
5. OPUS end card and `opus.mk` call to action.

All product copy is in Macedonian and limited to the currently operational
beauty-studio booking journey. No AI, payment, marketplace, or unverified
messaging claims are shown.

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run render:draft
npm run render
npm run render:master
npm run poster
```

The procedural soundtrack is generated by `npm run audio` and is original to
this project. `npm run dev` generates it automatically before opening Remotion
Studio. Final files are written to `out/` and are intentionally not committed.
