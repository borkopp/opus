# OPUS Landing — UI Kit

Recreates `opus-landing-page` marketing site: hero with dune-texture bg, feature grid, pricing card, footer with ghost wordmark.

## Components
- `Navbar.jsx` — floating blurred pill navbar; morphs on scroll
- `Hero.jsx` — full-viewport hero with `abstract-bg.jpg`, Cyrillic copy, italic Playfair accent on "владеете"
- `Features.jsx` — 4-column feature grid on radial terracotta glow
- `Pricing.jsx` — single plan card on dotted grid
- `Footer.jsx` — 4-column footer with giant outlined wordmark

## Source
Modeled after `github.com/borkopp/opus-landing-page` (Next.js 15 + Tailwind v4 + Framer Motion). Component implementations are simplified — same visual tokens, less code.

## Cyrillic
Copy is Macedonian to match the real production site. Swap to English by changing strings in each component.
