# OPUS Project Overview

This older package overview is superseded by the repository-wide [`docs/PRODUCT_SCOPE.md`](../docs/PRODUCT_SCOPE.md). Use that document as the single source of truth for positioning, priorities, active verticals, and expansion rules.

Current direction: OPUS is a beauty appointment SaaS for small beauty businesses in Macedonia. Hospitality and other verticals are dormant. Payments, autonomous AI features, loyalty, international expansion, and native consumer applications are deferred.

The dashboard and web marketplace golden booking journey comes first. The Expo/React Native and SwiftUI apps come last and must not be expanded or synchronized during the current web phase unless the user explicitly authorizes native work.
