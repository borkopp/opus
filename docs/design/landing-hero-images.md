# Landing hero artwork

The first slide now uses `studio-timeline.png`: the approved walnut scene with an original English timeline fitted to the monitor. All earlier versions and the other three slides are preserved. See [studio hero revisions](studio-hero-revisions.md) for the current asset and edit prompts.

The new homepage hero uses four original images created with the built-in image generation tool. The original hero is preserved unchanged in `opus-landing/components/hero.tsx` and can be viewed at `/hero-original` (excluded from search indexing).

The provided hero screenshot was a composition and lighting reference. The provided OPUS calendar screenshot was the interface reference for the desktop and laptop screens. Generated screen details are illustrative and may differ from the exact UI. No AI feature claims are added to this hero. The subjects are generated models, not customer testimonials.

Assets: `opus-landing/public/images/hero/{studio,calendar,team,clients}.png`. Full-quality source PNGs are served by Next.js Image with responsive sizing and quality 90.

The four tabs are manually selected, with image and copy transitions, keyboard navigation, and reduced-motion support. Copy and CTA destinations for both Macedonian and English are in `opus-landing/lib/hero-slides.ts`.
