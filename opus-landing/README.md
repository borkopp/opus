# OPUS Landing Page

This package is the marketing site for the current beauty appointment product in Macedonia. Its copy must describe only behavior that is genuinely available in the dashboard and web marketplace.

Read the repository-wide [product scope](../docs/PRODUCT_SCOPE.md) before product work. Do not advertise hospitality, payments, unsupported provider delivery, trial pricing, autonomous AI, international expansion, or native clients as active. The Expo/React Native and SwiftUI apps come last and are outside the current web phase.

## Development

```bash
npm install
npm run dev
```
