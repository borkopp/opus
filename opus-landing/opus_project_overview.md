# OPUS Project Overview

This older package overview is superseded by the repository-wide [`docs/PRODUCT_SCOPE.md`](../docs/PRODUCT_SCOPE.md). Use that document as the single source of truth for positioning, priorities, active verticals, and expansion rules.

Current direction: OPUS is a beauty appointment SaaS for small beauty businesses in Macedonia. Hospitality and other verticals are dormant. Autonomous AI features, loyalty, international expansion, and native consumer applications are deferred.

The dashboard and automatic `{slug}.opus.mk` studio-website booking journey come first. The `opus-mk` marketplace and native clients are deferred and must not be expanded during the current web phase unless the user explicitly authorizes that work.
